### Improvements / 更新内容

- Search market assets by name or ticker, keep favorites at the top, and switch to a favorites-only list. Favorites are saved locally.
- News distinguishes the last successful refresh, cached reports, partial source failures, and unavailable sources. Failed refreshes preserve useful cached reports without presenting them as freshly fetched.
- Automatic refresh prioritizes the active view and reduces requests while the window is hidden.
- City cards, map labels, and weather details consistently display Celsius as `°C`.
- Selecting or copying the translation panel's original text, result, explanation, or labels does not trigger another translation.
- Includes a refreshed public market snapshot and the accumulated reliability, configuration protection, responsive layout, and packaging improvements.

- 行情支持名称和代码搜索、自选置顶及仅看自选，自选保存在本机。
- 新闻区分真实成功更新时间、缓存数据、部分数据源失败和数据源不可用。刷新失败时保留已有报道，同时清楚标明状态。
- 自动刷新优先处理当前页面，窗口隐藏时减少后台请求。
- 城市卡片、地图和天气详情统一显示 `°C`，补齐摄氏度的小圆圈。
- 翻译面板的原文、译文、解释和标签支持正常选中复制，不会反复触发自动翻译。
- 更新内置公共行情快照，并包含此前积累的稳定性、配置保护、响应式布局和安装打包改进。

### Windows installation / Windows 安装

Run **Codex-World-Setup-x64.exe** and choose Simplified Chinese or English. Install over the existing copy to keep using the same application location. The installer package includes the Python runtime; no separate Python installation is required. User configuration stays local.

运行 **Codex-World-Setup-x64.exe**，选择简体中文或英文，安装到现有应用目录即可升级。安装包自带运行环境，无需另装 Python，用户配置保存在本机。
